My Projects

Featured Project

EATRS — Explainable Adaptive Threat Response System

EATRS is a cybersecurity project for network traffic monitoring and anomaly detection. It uses Scapy for traffic capture and feature collection, and Scikit-learn’s Isolation Forest to identify anomalous activity. SHAP supports explanation of model results, while sensor evidence from an ESP32 can be correlated with network observations. The Django-based dashboard presents live monitoring information and supports an adaptive response workflow.

Technologies: Python, Scikit-learn (Isolation Forest), SHAP, Scapy, Django, and ESP32.
